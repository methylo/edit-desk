# 편집 데스크 (edit-desk)

이미 쓴 한국어 원고를 일곱 단계(0~6)로 고치는 Claude 스킬입니다. 원고를 잠그고, 독자와 편집자 역할을 차례로 불러 진단하고, 작가가 승인한 수정만 반영한 뒤 전후를 대조합니다. 마지막에는 게시 전 교정과 제목·도입·결론 후보까지 냅니다. 원고의 관점, 경험 공개, 판단 강도, 게시 여부는 작가가 정합니다.

## 일곱 단계와 네 관문

| 단계 | 하는 일 | 관문 |
|---|---|---|
| 0 | 원고 접수·잠금 — 기준본, 범위, 중심 판단, 보존 영역 | 확인 |
| 1 | 진단 — 독자 반응과 편집자 진단 | 제안 |
| 2 | 수정 제안·승인 — 이슈 ID별 제안, 저자 확인 질문 | 제안 |
| 3 | 반영 — 승인 항목만 수정 | 결과 |
| 4 | 전후 대조 — 이슈별 해결·부분 해결·보류·새 문제 | 결과 |
| 5 | 게시 전 교정 — 게시 가능 / 게시 보류 / 재편집 필요 | 결과 |
| 6 | 제목·도입·결론 후보와 선택 반영본 | 마무리 |

각 관문에서 단계 카드와 추천 요청, 다른 요청을 따로 보여 주고 작가가 확인한 뒤 넘어갑니다. 2,500자 이하 원고는 빠른 개선 경로로 진행하고, 책 챕터는 스킬 밖의 책 집필팩 기준을 함께 읽습니다.

## 구성

```text
edit-desk/
├── SKILL.md                    데스크 규칙 — 관문 진행, 절대 규칙, 출력 형식
├── roles/
│   ├── reader.md               독자 역할 브리프 — 반응과 막힘만 보고
│   └── editor.md               편집자 역할 브리프 — 제안·반영 규격, 사실 보존 대조
├── voice/                      작가 문체 기준 (hong-voice-reference v1.7.0 통합본)
│   ├── 00-minimum-card.md      문체 최소 카드 — voice 파일을 못 열었을 때만
│   ├── 01-voice.md             1층 시선·어조·논리·리듬·마무리
│   ├── 02-glossary.md          2층 단어·문장 선택
│   ├── 03-anti-traces.md       3층 AI 흔적·금지어·흔적 지수
│   ├── 04-examples.md          승인 원문 — 판정이 갈릴 때 기준
│   └── 05-corrections.md       교정 이력과 승격 절차
├── references/
│   ├── gate-1-intake.md        접수·0단계
│   ├── gate-2-diagnosis.md     1·2단계
│   ├── gate-3-apply.md         3·4·5단계
│   ├── gate-4-finish.md        6단계
│   ├── finish-evidence.md      제목·도입·결론 후보의 근거 등급과 추천 판정
│   ├── practice-mode.md        가상 원고 연습 모드
│   ├── history-template.md     편집 이력 파일 형식
│   └── maintenance.md          문체 기준 갱신 절차·개정 기록
└── scripts/
    └── check.py                기초 수치, 승인 문장 치환, 전후 대조, voice 버전 확인
```

다른 스킬을 호출하지 않습니다. 필요한 기준은 모두 이 폴더 안에 있습니다.

## 설치

- **Claude 앱(claude.ai·데스크톱)**: [Releases](https://github.com/methylo/edit-desk/releases/latest)에서 `edit-desk.skill`을 내려받아 설정 → 기능(Capabilities) → 스킬(Skills)에서 업로드합니다.
- **Claude Code**: `edit-desk/` 폴더를 `~/.claude/skills/`에 복사합니다.

`scripts/check.py`는 Python 3로 실행되므로, Claude 앱에서는 코드 실행 기능이 켜져 있어야 합니다. Team·Enterprise 요금제는 관리자가 스킬 기능을 켜야 등록할 수 있습니다.

## 호출 예시

```
이 원고 개선해줘.

[원고 붙여 넣기 또는 파일 첨부]
```

- `게시용으로 고쳐줘`, `구조부터 진단해줘`, `수정 이력 남기며 고쳐줘`
- `이 짧은 글 가볍게 고쳐줘` — 2,500자 이하 빠른 개선
- `3장 원고 진단해줘` — 책 챕터 한 편 단위
- `가상 원고로 연습하자` — 연습·시연용
- `지난번 ED-02, ED-03만 다시 봐줘` — 표적 재확인

처음에 원고 종류와 발행 채널을 한 번 묻습니다.

## 내 문체로 바꿔 쓰기

`voice/`에는 HONGS LAB 홍순성의 문체 기준이 들어 있습니다. 받은 그대로 쓰면 이 기준으로 원고를 고칩니다. 자기 문체로 쓰려면 `voice/01~05`의 내용을 자기 기준과 승인 원문으로 바꾸고, 다섯 파일 머리의 버전 줄을 같게 맞춘 뒤 폴더를 다시 묶어 설치합니다. 자세한 절차는 `references/maintenance.md`에 있습니다.

```bash
python3 edit-desk/scripts/check.py --voice
```
