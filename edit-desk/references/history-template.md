# 편집 이력 형식

> 편집 이력을 저장할 때만 읽는다. 원고 본문과 섞지 않고 `YYMMDD {원고 제목}_편집이력.md`로 원고와 같은 폴더에 둔다. 이슈 ID(ED-01…)·High·Mid 같은 내부 표기는 이 파일에서만 쓴다.

```text
# 편집 이력 — {원고 제목}

## 실행 정보
- 기준 원고:
- 편집 모드:
- 편집 범위:
- 실행일:

## 이슈와 수정
### ED-01
- 단계:
- 원고 위치:
- 문제:
- 수정 전:
- 수정 후:
- 수정 이유:
- 상태: 반영 / 보류 / 미반영 (거절 사유는 사용자 문장 그대로, 없으면 "사유 없음")

## 전후 대조
- ED-01:

## 제목·도입·결론
- 범위 판정(1/4 → 4/4):
- 제목: 고른 안 / 원문 유지
- 도입:
- 결론:

## 저자 확인
- Q1:

## 실행 지표
- 모드 / 원고 분량:
- 제안 · 반영 · 보류 · 유지 · 거절:
- 새 문제 · 범위 밖 변경 · 숫자 보존 불일치:
- 저자 확인 (답함/남음):
- 판정:
- 작가가 반영 뒤 직접 다시 고친 곳: (있으면 위치. 편집이 놓친 지점이다)

## 공용 승격 후보
- 반복 근거와 사용자 승인 전에는 비워 둔다.
```
